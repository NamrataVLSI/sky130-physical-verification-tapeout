# Module 3 — SKY130 DRC Rules and Verification Labs

## Overview

This module focuses on understanding and applying **SKY130 design rules** using Magic.

The theory section introduces front-end and back-end physical design rules, while the lab section provides hands-on exercises for identifying, understanding, and correcting DRC violations.

For this repository, I am documenting the practical labs from **PV_D3SK2 — Labs for all DRC Rules**.

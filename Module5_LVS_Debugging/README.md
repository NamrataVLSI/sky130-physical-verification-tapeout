# Module 5 — LVS and Debugging with Netgen

## Overview

This module focuses on **Layout Versus Schematic (LVS)** verification using **Netgen**.

The labs begin with very simple SPICE netlists to understand how Netgen compares circuit connectivity and reports matches and mismatches. The later exercises build toward more realistic LVS cases involving subcircuits, black boxes, low-level SPICE components, analog blocks, standard cells, macros, digital PLLs, and property checking.

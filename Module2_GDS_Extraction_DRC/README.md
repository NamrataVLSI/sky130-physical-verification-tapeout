# Module 2 — GDS Read/Write, Extraction and Physical Verification

## Overview

This module focuses on working with SKY130 GDS data in Magic and building the physical-verification flow around imported standard-cell layouts.

The labs cover:

- Reading SKY130 GDS into Magic
- Port handling
- Abstract views
- Basic extraction
- DRC setup
- LVS setup
- XOR setup and verification

# SKY130 Physical Verification & Tapeout

Hands-on physical verification of SKY130 designs using open-source IC design and verification tools.

This repository documents my work with device layout, DRC, LVS, parasitic extraction, GDS verification, antenna checks, density/ERC checks, and hierarchical physical verification.

## Tools

- SKY130 PDK
- Magic VLSI
- Netgen
- Xschem
- ngspice
- KLayout
- OpenLANE
